☁️ Cloud Sync
Sync this tracker across browsers, profiles, and computers using a free Firebase project. One-time setup: create a project at console.firebase.google.com, enable Firestore Database, then paste your web app config below. Use the same Sync Key on every device you want linked together.
⚠️ Security note Your Firebase config and Sync Key are stored in this browser's localStorage and are visible in plain text (e.g. via DevTools, or in a JSON backup you export). Anyone who obtains your Sync Key can read and overwrite this data, because there's no login step — just matching keys. Use a long, unguessable Sync Key (not your name), never share it, and lock down your Firestore database with rules that scope access to a single document instead of leaving the whole database open. Suggested starting rule for your project's Firestore > Rules tab:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /trackers/{syncKey} { allow read, write: if syncKey.size() >= 20; } } }
